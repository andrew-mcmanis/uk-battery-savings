# UK Battery Savings

A privacy-first UK home battery savings calculator.

The calculator estimates whether charging a home battery on cheap off-peak electricity and using it during peak-rate hours could reduce annual electricity costs.

## Current features

- UK home battery savings calculator
- Annual saving estimate
- Monthly saving estimate
- Payback period estimate
- Break-even battery cost estimate
- Privacy-first landing page
- About, Privacy, Disclaimer and Terms pages
- No login
- No database
- No stored calculator inputs

## Tech stack

- Next.js
- TypeScript
- Tailwind CSS
