# Weekly Traffic Review

## Purpose

Use this checklist once per week to review whether Home Battery Savings is gaining visibility, traffic and useful engagement.

Do not overreact to one day of data. Look for trends over several weeks.

---

## 1. Google Search Console

Check:

- [ ] Total clicks
- [ ] Total impressions
- [ ] Average CTR
- [ ] Average position
- [ ] Pages receiving impressions
- [ ] Queries receiving impressions
- [ ] Coverage / indexing issues
- [ ] Sitemap status

Key pages to check:

- [ ] /
- [ ] /tools
- [ ] /guides
- [ ] /methodology
- [ ] /home-battery-quote-comparison-uk
- [ ] /home-battery-savings-examples-uk
- [ ] /home-battery-quote-checklist-uk
- [ ] /is-a-home-battery-worth-it-uk
- [ ] /home-battery-without-solar-uk
- [ ] /home-battery-payback-period-uk

Questions to answer:

- Which pages are getting impressions?
- Which pages are getting clicks?
- Which search queries are appearing?
- Are pages indexed properly?
- Are any pages getting impressions but poor CTR?
- Are any pages ranking around position 8–20 that could be improved?

---

## 2. Bing Webmaster Tools

Check:

- [ ] Sitemap status
- [ ] Indexed pages
- [ ] Search keywords
- [ ] Crawl issues
- [ ] Clicks and impressions if available

Questions to answer:

- Is Bing discovering the same main pages?
- Are any crawl errors appearing?
- Are any pages missing that Google has found?

---

## 3. Vercel Web Analytics

Check:

- [ ] Total visitors
- [ ] Top pages
- [ ] Referrers
- [ ] Countries
- [ ] Device types
- [ ] Browser types

Questions to answer:

- Which pages are people actually visiting?
- Are visitors reaching /tools?
- Are visitors reaching /home-battery-quote-comparison-uk?
- Are visitors mostly mobile or desktop?
- Are visitors coming from search, direct, or referrals?

---

## 4. Vercel Speed Insights

Check:

- [ ] Homepage performance
- [ ] /tools performance
- [ ] /guides performance
- [ ] /home-battery-quote-comparison-uk performance
- [ ] Any poor Core Web Vitals
- [ ] Any slow pages

Questions to answer:

- Is the homepage fast enough?
- Is the quote comparison page slow?
- Are there layout shift problems?
- Are mobile users getting a poor experience?

---

- [ ] No obvious layout issues

---

## 6. Decision log

Record the weekly decision:

- Keep as-is
- Improve an existing page
- Add internal links
- Add a new guide
- Improve a title/meta description
- Fix a UX issue
- Fix a performance issue

Write the decision here:

```text
Week: 2026-05-22
Observation: Local manual review found three improvement opportunities before meaningful traffic review data is available: homepage snippet clarity, stronger homepage path to tools, and clearer quote comparison explanation.
Decision: Improve existing pages and internal links now; defer analytics-led decisions until Search Console, Bing and Vercel data are available.
Action: Updated homepage metadata, added a homepage tools CTA, improved the quote comparison explanation, removed the external Google font dependency, improved currency input affordance, added compact mobile header links, added vendor-neutral popular battery size shortcuts, and completed the local SEO/internal-link audit.
```
